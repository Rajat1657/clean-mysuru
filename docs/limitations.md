# ⚠️ Limitations & Future Roadmap

## Known Limitations
1. **Camera Occlusion**: Heavy rain, fog, or severe physical lens obstruction can lower detection accuracy below standard confidence thresholds.
2. **Bandwidth in Remote Wards**: High-resolution video streaming from outlying rural/suburban ward edges requires video compression before transmission.

## Future Roadmap
- [ ] **Mobile App Integration**: Dedicated React Native app for field workers to receive push alerts and upload resolution photo proofs.
- [ ] **AI Route Optimization**: Dynamic garbage truck route planning based on real-time bin fill level detections across Mysuru.
- [ ] **Citizen Rewards Program**: Gamified public reporting system for verified civic issues.
