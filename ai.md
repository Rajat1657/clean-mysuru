# 🤖 Clean Mysuru — AI Usage Disclosure

## AI Assistance & Tooling Declaration

During the design, development, and optimization of **Clean Mysuru**, AI tools and model acceleration frameworks were leveraged to maximize code quality, real-time computer vision performance, and modern web application UI/UX standard adherence.

---

## 1. Computer Vision & Edge AI Models
- **YOLOv8 Small Detection Model**:
  - Custom fine-tuned weights trained to detect civic waste artifacts: solid garbage dumping, open litter bins, clogged storm drains, and road potholes.
  - Accelerated with **PyTorch / OpenCV DNN** backends for low-latency multi-stream inference on edge nodes.
- **Multiscale Retinex Low-Light Image Enhancement**:
  - Computational vision algorithm based on logarithmic color-space dynamic restoration to enhance low-light night-time CCTV/mobile capture before object detection.

---

## 2. Development & Code Generation Assistance
- **AI Coding Assistant (Antigravity / Gemini)**:
  - Assisted in designing the **Vite React UI Component System** with HSL glassmorphism styling, zero-flicker state polling, and custom map visualizer.
  - Automated ROS 2 Python node scaffolding, API endpoint routing (`FastAPI/Flask`), dynamic mock simulation, and test automation.
- **Code Refactoring & Documentation**:
  - Automated generation of Markdown documentation, clean repository structuring, and git release tagging.
